# Student Performance & Placement Analytics

## About the Project

This project aims to analyze the relationship between students' academic performance, technical skills, internships, and placement outcomes.

## Objectives

- Analyze student academic performance
- Explore factors associated with placement outcomes
- Analyze the relationship between skills and placement
- Create meaningful visualizations
- Build an interactive analytics dashboard

## Technologies

- Python
- Pandas
- NumPy
- SQL
- Matplotlib
- Streamlit
